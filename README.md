# Wawa Cycle Tracker

Mobile-first Thai app for tracking menstrual cycles. Cycle entries, symptoms, moods, and notes are stored locally on the device. Forecasts are estimates, not medical advice or contraception.

## Android build

GitHub Actions builds a debug APK when code is pushed to `main`, uploads it as an artifact, and updates the `cycle-buddy-latest` release.

## Initial scope

This is the first Android prototype. Local notification scheduling and native biometric/app-lock support are not yet connected.
